Biogas Production in Europe - Eurobserv'ER

This dashboard explores biogas production in Europe based on data from Eurobserv’ER. The dataset includes biogas production by various methods (thermal, landfill, anaerobic digestion of sewage sludge, and other anaerobic fermentation) and spans multiple years. Use the interactive filters and charts below to discover which countries are leading in biogas production, how production methods vary, and how trends evolve over time.
