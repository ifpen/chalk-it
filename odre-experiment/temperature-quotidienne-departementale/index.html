About this dashboard

This front-end–only dashboard uses the Explore API v2.1 to fetch and aggregate data from the “temperature-quotidienne-departementale” dataset. To handle API limits efficiently:

  • Monthly/national trends use server-side aggregation with group_by and select.
  • Map values are aggregated by department for the selected month.
  • Department drill-down fetches all daily records in a date range with paginated requests (limit=100, offset steps).
  • We only select the fields needed via the select parameter to minimize payload.

API: https://odre.opendatasoft.com/api/explore/v2.1/catalog/datasets/temperature-quotidienne-departementale/records · If any call cannot return its full result due to API constraints, you’ll see a warning above.
