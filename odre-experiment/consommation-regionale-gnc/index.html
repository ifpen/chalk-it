GNC Regional Consumption Dashboard

This dashboard shows compressed natural gas (GNC) consumption across different French regions, illustrating how usage changes by year and location. You can select a year, view a color-coded map, and explore the top regions in a bar chart.

Use the dropdown to view consumption data for a specific year. Hover on a region in the map or check the bar chart to see GNC consumption figures (in GWh, PCS).

Data Story: Notice that certain regions consistently have higher GNC consumption, reflecting possibly larger transportation usage or station availability. Interact with the map to see how consumption distribution changes year to year.
