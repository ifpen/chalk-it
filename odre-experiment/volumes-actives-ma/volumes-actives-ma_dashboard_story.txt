3. FRONT-END ONLY: HANDLING BIG DATA
────────────────────────────────────────────────────────

Even though you have a small sample, the real dataset can be large. Strategies to handle large data using only front-end technologies include:

1. Server-side filtering & pagination  
   • Most public APIs (like the Opendatasoft one) allow you to request data in pages (e.g., “&facet=year” or “start=...&rows=...”).  
   • Retrieve data incrementally, then combine into client-side data structures.  

2. Data summarization  
   • Instead of pulling all records at once, request only aggregated endpoints (if the API provides them) or do on-the-fly grouping (by year, by filière, etc.) to avoid rendering every single row in the UI.  

3. Lazy loading or streaming  
   • Fetch additional data only when the user adjusts filters or zooms into details.  

4. Caching & local storage  
   • If your dashboard changes among a few filters repeatedly, you might keep data in memory or local storage so it isn’t refetched.

5. IMPLEMENTATION STEPS (ONLY FRONT-END)

Here’s a concise workflow for creating this dashboard:

1. Fetch the Data  
   • Use fetch() or Axios in plain JavaScript (or a framework).

     fetch("https://odre.opendatasoft.com/api/explore/v2.1/catalog/datasets/volumes-actives-ma/records?start=0&rows=100")  
   • Optionally, loop calls in increments (start=0, rows=100 / start=100, rows=100, etc.) until you collect desired data.

2. Process & Transform  
   • Parse the JSON for relevant fields (e.g., records[i].fields might contain volume, date, cost).  
   • Convert date strings to JavaScript Date objects for consistent time-series plotting.  
   • Group or bucket data by month/year if you want aggregated views.  
   • Summarize cost averages or volumes if the dataset is large.

3. Visualize  
   • Libraries like D3.js, Chart.js, Plotly.js, or Highcharts can handle interactive charts.  
   • For each chart:  
     – Provide tooltips to highlight data points.  
     – Complement with legends & color codes for easy reading.  

4. Add Interactivity  
   • Filter for filière or date range: On user selection, re-aggregate or re-render the charts.  
   • Hover or click events: Reveal deeper numbers or highlight connected charts.

5. Storytelling Flow  
   • Visually guide the user: Start with an “Overview” section, then reveal deeper insights.  
   • Consider adding short textual explanations by the charts: “Notice how cost increases in months with more tense situations.”
