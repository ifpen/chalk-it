Gas Consumption Dashboard

About This Dashboard

This dashboard presents national gross gas consumption data for the dataset conso-jour-nat-eldgrd-grt. It showcases how daily usage evolves over time and offers insights into consumption patterns and potential seasonal trends.

Data Source: Opendatasoft: conso-jour-nat-eldgrd-grt

Note: The dashboard fetches data directly from the live API endpoint.

Filter by Date Range

Adjust the date range to focus on a specific period. The line chart and summary statistics will update accordingly.

Daily Gas Consumption Over Time

Operator / Sector Totals

This bar chart sums daily consumption by operator or sector over the selected date range. (Note: In the sample data shown, only "NaTran" appears, but multiple operators may be present in the live dataset.)

Monthly Consumption (Seasonal Aggregation)

Aggregated monthly totals can reveal seasonal trends (winter spikes, summer dips, etc.).
